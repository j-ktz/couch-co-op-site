Pocketarr support

Email support@couchcoopstudios.com. A real person reads every message. In the app, Settings, Send feedback opens an email with your app and iOS versions filled in.

Where do I find my API key?

In Sonarr, Radarr or Lidarr, open Settings, then General, and look for API Key. Copy it into Pocketarr when you add the server. On many servers you can tap Find key instead, and Pocketarr asks the server for the key its own web page already shows. The key is stored in your iPhone's Keychain and is sent only in a request header to your own server.

How do I add Plex?

Tap Add Plex Server and choose Sign in with Plex. The sign-in happens on Plex's own page, and Pocketarr never sees your Plex password. Pocketarr then shows what's playing and what was recently added on your own Plex server.

Can Pocketarr find my servers for me?

Yes. Find Servers on My Network checks your home network for apps answering on their usual ports, shows one row per machine, and Set Up All adds what it finds. It sends no keys or passwords, and the results aren't saved.

Pocketarr can't reach my server

Check the address first: include http or https and the port, for example http://192.0.2.10:8989. If your server runs on your home network, allow Local Network access when iOS asks (Settings, Pocketarr, Local Network). Away from home you need a way in, such as Tailscale or another VPN, or a reverse proxy.

My server uses a self-signed certificate

You can trust the certificate for that one server in its settings. It doesn't trust certificates for any other server.

I use Cloudflare Access or a reverse proxy

Add the custom headers it needs when you set up the server. Header values are stored in the Keychain, like the API key.

My widgets say "Open Pocketarr" or look old

Widgets show what the app last saved, and they say how old it is. Open the app once to refresh. Background App Refresh (iOS Settings, General) lets Pocketarr update the summary while the app is closed, but iOS decides when it runs.

Can Pocketarr notify me when something finishes?

Pocketarr has no server of its own, so it can't send notifications while it's closed. Settings has a step-by-step guide to the notifications Sonarr and Radarr can send you themselves, through ntfy or Pushover.

Can I try it before adding my own server?

Yes. Tap Try the Demo on the first screen to look around with sample servers and invented shows. Turn the demo off in Settings.

What is free and what is Pro?

Free covers one Sonarr server and one Radarr server, the dashboard, calendar and queue, and the small Up Next widget. Pro is a one-time $14.99, with a 7-day free trial and no subscription. It adds every other widget and size (including all the Lock Screen widgets), more servers, and your download client's queue. Family Sharing is included.

Restoring Pro

On a new phone, open Settings in Pocketarr and tap Restore Purchases. Pro follows your Apple Account.

Does it get shows or movies for me?

No. Pocketarr is a window onto the Sonarr, Radarr, Lidarr and Plex servers you already run. Your servers do the work, and anything that changes a server asks you first. Pocketarr doesn't provide any shows, movies, music or files.

Deleting a server

Open the server in Settings and delete it. Its entry, API key or Plex token, header values and cached posters are removed from your iPhone. Nothing changes on the server itself.
